Geometry Calculator

A menu-driven Python application that performs various geometric calculations for 2D and 3D shapes. This project helps users calculate area, perimeter, volume, surface area, diagonals, distance between points, and more using simple mathematical formulas.

Features
Supports multiple geometric shapes
Menu-driven console application
Performs both 2D and 3D calculations
Includes formulas for circles, triangles, cubes, cylinders, cones, and more
User-friendly interactive interface
Continuous execution until the user exits

How to Run the Project
Install Python on your system.
Copy the Python code into a file named geometry_calculator.py
Open terminal or command prompt.
Run the following command:
python geometry_calculator.py
